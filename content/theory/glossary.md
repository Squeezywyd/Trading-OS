| Term | Meaning |
| --- | --- |
| AMD | Accumulation, Manipulation, Distribution |
| ATM | Advanced Trade Management (NinjaTrader bracket for stop/targets) |
| BSL / SSL | Buy-side / sell-side liquidity |
| BOS | Break of structure (continuation) |
| MSS / CHoCH | Market structure shift / change of character (reversal) |
| OB | Order block |
| RB | Rejection block |
| FVG | Fair value gap |
| IFVG | Inverse fair value gap |
| BISI / SIBI | Buyside imbalance sellside inefficiency / sellside imbalance buyside inefficiency |
| CE | Consequent encroachment, the 50% of a gap |
| OTE | Optimal trade entry, 62 to 79% retracement |
| PD array | Premium/discount array, a zone where price reacts (OB, FVG, RB, breaker) |
| EQH / EQL | Equal highs / equal lows |
| PDH / PDL | Previous day high / low |
| PWH / PWL | Previous week high / low |
| NWOG / NDOG / ORG | New week / new day / opening range gap |
| SMT | Smart money tool, divergence between correlated markets |
| Judas swing | False move at session open against the true direction |
| Displacement | Strong one-directional move leaving an FVG |
| DOL | Draw on liquidity, the pool price is heading to |
| Turtle soup | Sweep of an old high/low followed by reversal |
| R | Multiple of initial risk |
